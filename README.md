# Portofolio Naila Shabrina

Situs statis (HTML, CSS, JavaScript), tanpa build.

## Cara tayang di GitHub Pages
1. Buat repository baru, misalnya `portofolio` (atau `username.github.io` agar alamatnya lebih pendek).
2. Upload semua isi folder ini (index.html, assets, dashboard, data).
3. Settings > Pages > Source: Deploy from a branch > branch `main`, folder `/ (root)` > Save.
4. Tunggu 1 sampai 2 menit. Alamat: `https://username.github.io/portofolio/`
5. Tempel alamat itu di LinkedIn (Contact info > Website, dan bagian Featured).
